# We-Read

一个以本机存储和本机服务为核心的公众号、YouTube 与 Twitter 阅读、订阅和归档工具。Twitter 中文翻译会按用户启用的模型配置调用外部模型，原文、译文和阅读状态仍只保存在本机。

打开：<http://localhost:8041/>

## 日常使用

- **管理订阅**：粘贴任意一篇 `mp.weixin.qq.com/s/...` 文章链接，即可在本机解析公众号身份并加入订阅。
- **拉取更新**：右上角按钮只抓取增量；首次订阅默认抓取最近 50 篇。按钮左侧会先显示索引处理动画；文章索引写入后会立刻出现在网页里，并切换为 Markdown 与图片归档的 `已完成 / 总数` 进度。按钮会自动启动项目专用的 Chrome 窗口；第一次在该窗口登录微信读书，之后会持续复用本地登录态。微信读书出现验证码时，需要在这个窗口里手动完成验证。
- **阅读原文**：点击任意文章会直接在浏览器新标签页打开微信原文；右侧星标仍可加入收藏待读。
- **书架分组**：固定为“宏观、价值、成长、Youtube、Twitter”五类。新加入的来源默认归入“价值”，之后可拖动卡片或使用卡片下方菜单手动调整。最近一天与最近 7 天会按当前分组细排，只显示确实有文章的分组。
- **YouTube 频道**：使用 `youtube/sync.py subscribe` 登记频道，频道默认进入 Youtube 分组。点击“同步 YouTube”后通过频道 RSS 增量发现视频，优先保存人工字幕，其次自动字幕，并生成中文在前、英文在后的带时间戳 Markdown。视频标题打开 YouTube，右侧“字幕”打开本地阅读器。
- **Twitter 账号**：Twitter Tab 固定分为“高频”和“低频”两个标签，由用户给每位 Leader 选择。高频流只显示并同步最近 2 周，低频流只显示并同步最近 2 个月；每个分类内部按原始发布时间倒序，首屏 30 条并在下滑时分批加载。项目使用独立的 `chrome-twitter` 登录资料，Twikit 只读复用 X 登录态以取得实时公开时间线；同步前会在专用窗口仍运行时刷新私有 Cookie 文件。账号还可以单独屏蔽/恢复，屏蔽只隐藏信息流、不停止同步。短推文默认显示完整中文译文，英文折叠；超过 500 个英文词的长推文显示采集期生成的中文标题与摘要，完整中英文本仍保存在本地 Markdown。
- **Twitter 删除**：Twitter 条目的星标旁有一个减号。确认后会删除本地 Markdown、书库条目、收藏和划线，并写入删除标记，之后同步不会重新导入该条推文。
- **超级大盘**：独立 Tab 用分类书架保存常看的市场 Dashboard。点击整张卡会在新标签页打开原网站；“关注 Dashboard”可以继续添加名称、网址、分类和简介，右上角 × 只移除本机保存的链接。首张卡为 [Kim Premium](https://kimpremium.com/) 的韩国散户杠杆与去杠杆监控。
- **设置**：可调整每日抓取上限、请求间隔和首批文章数量。默认值偏保守，减少触发风控的概率。
- **移除订阅**：停止之后的同步并从阅读器隐藏；已归档文章会保留，避免误删知识资产。

## 目录

```text
we-reader/
├── app/                 # 本地网页与管理接口
├── fetcher/             # 微信读书订阅、增量抓取与归档逻辑
├── youtube/             # YouTube 频道发现、字幕同步和 Markdown 归档
├── twitter/             # Twitter 公开账号订阅、增量同步与 Markdown 归档
├── data/                # 全部用户数据
│   ├── 文章/             # Markdown 正文和本地图片
│   ├── 数据/             # 书库、收藏、分组与抓取状态
│   ├── 日报/             # 每次同步生成的日报
│   └── feed.xml          # RSS
└── README.md
```

因此备份或迁移时，直接复制整个 `wechat-second-brain` 目录即可。新机器需要安装 Node.js、Python 3.10+、Chrome 和已登录的 Codex CLI；首次点击公众号拉取后，在自动出现的专用 Chrome 窗口中登录微信读书即可。YouTube 不需要 API Key；Twitter 当前通过独立的专用 Chrome 登录 X，Cookie 只保存在私有 `data/` 中。Twitter 翻译会把待翻译的公开推文文本提交给配置的翻译模型。

## 手动启动

```bash
cd app
node server.mjs
```
