ADD A PUBLIC ACCOUNT

添加公众号

粘贴该公众号任意一篇文章链接。系统会在本机解析公众号身份、加入书架，并在下次刷新时抓取文章。

ADD A YOUTUBE CHANNEL

添加 YouTube 频道

粘贴频道主页或 /videos 链接。频道会进入 Youtube 分组；点击“同步 YouTube”后导入最新视频和可用字幕。

ADD A TWITTER ACCOUNT

添加 Twitter 账号

输入 @用户名或 x.com 用户主页。这里只订阅公开推文到本地书架，不会操作你的 Twitter 账号，也不需要登录。
